## 🛒 Key Capabilities

- **Automated Perishable Shelf Tracking:** Categorizes inventory lots and alerts managers prior to critical freshness deadlines.
- **Modular MVC Architecture:** Decoupled controllers (`auth.controller.js`, `clientes.controller.js`), services, and routes.
- **Client & Membership Profiling:** Tracks frequent shopper loyalty metrics and personalized discount incentives.
- **Comprehensive API & Tooling:** Complete project guidelines with PR checklists, Copilot instructions, and standardized error schemas.

```bash
# Clone the repository

npm install

# Start development server
```
